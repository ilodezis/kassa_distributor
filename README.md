# Kassa Distribution Tool 📊

Инструмент для автоматического распределения касс (сделок) между менеджерами сопровождения. 

Программа анализирует выгрузку из Excel, распределяет нагрузку на основе математической модели со штрафами (cost function) и предоставляет удобный UI для управления параметрами команды.

---

### Основные возможности

* **Умная балансировка:** Распределение касс по менеджерам с выравниванием общего количества (допуск ±5) и тарифных периодов (1 / 3 / 12 месяцев, допуск ±3).
* **Управление командой через UI:** Встроенный редактор менеджеров. Назначение ролей (`is_support`) и индивидуальных лимитов (`cap`) с возможностью массового редактирования (Multi-select).
* **Сохранение конфигурации:** Настройки команды сохраняются в `managers.json` — больше не нужно лезть в код при изменении штата.
* **Минимизация миграций:** Сохранение текущих привязок там, где это возможно. Оплаченные кассы зафиксированы жестко.
* **Аналитика и экспорт:** Генерация развернутого отчета в Excel (листы: итоговое распределение, summary, лог перемещений, логи проверок) и визуализация результатов в виде графика.

---

### Важные правила распределения ⚖️

1. **Заморозка оплат:** Если `Оплачен ИНН = 1` и касса уже находится на менеджере сопровождения — она **не перемещается**.
2. **Внешний пул:** Кассы (как оплаченные, так и нет), числящиеся на менеджерах НЕ-сопровождения, принудительно переносятся на менеджеров сопровождения.
3. **Индивидуальные лимиты (Cap):** Лимиты настраиваются гибко для каждого человека. Алгоритм равномерно распределяет кассы между менеджерами с лимитом (до их границы) и теми, у кого лимита нет.
4. **Консервативный ребаланс:** Неоплаченные кассы внутри отдела сопровождения двигаются минимально, только если это необходимо для выравнивания общих таргетов и долей тарифов.

### Требования 🛠️

* Python 3.10+

**Зависимости:**
```bash
pip install pandas openpyxl matplotlib
```
> *Примечание: Для работы интерфейса требуется библиотека `tkinter`. На Windows и macOS она устанавливается вместе с Python, на Linux может потребоваться пакет `python3-tk`.*

---

### Как использовать (Workflow) ⚙️

1. **Загрузить Excel:** Нажми кнопку загрузки исходного файла с кассами.
2. **Актуализировать менеджеров:** * Нажми «Подтянуть менеджеров из Excel», чтобы новые имена из выгрузки попали в базу.
   * Перейди во вкладку **«Менеджеры»**. Выдели нужных сотрудников (можно использовать `Ctrl`/`Shift` для массового выбора), отметь их как *«Участвует в сопровождении»* и задай лимиты (*Cap*), если требуется.
   * Нажми **«Сохранить managers.json»**.
3. **Запустить распределение:** Нажми соответствующую кнопку в верхнем меню.
4. **Проверить результаты:** Изучи вкладки `Summary` (сводка по каждому), `Moves` (кто кому передал), `Checks` (проверка на отсутствие логических ошибок) и `Chart` (график).
5. **Сохранить результат:** Нажми «Сохранить результат», чтобы экспортировать итоговый Excel-файл.
